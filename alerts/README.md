# التنبيهات (Cloud Functions — codebase `alerts`)

ترسل ملخصاً يومياً بالتنبيهات الجديدة إلى البريد وإشعارات الهاتف (إشعارات المتصفح للمنصة المثبّتة على الهاتف أو الكمبيوتر):

- مخزون منخفض (أصناف الويب حسب الحد الأدنى أو حد إعادة الطلب، ومنتجات نقطة البيع حسب حد عام)
- صلاحية قريبة لمنتجات نقطة البيع
- فواتير بيع آجلة مستحقة أو متأخرة (رصيد الزبون يُوزَّع على فواتيره من الأحدث، والأقدم يُعتبر مسدداً أولاً)
- ديون متأخرة (جزء من رصيد المدين عمره أكثر من المدة المختارة)
- شيكات مستحقة

الحساب نفسه في `src/shared/alerts.ts`، وهو نسخة من `web_sales/web/src/lib/alerts.ts` (الجرس وصفحة التنبيهات في الويب). بعد تعديل نسخة الويب: `npm run sync`. اختبار يتأكد أن النسختين متطابقتان.

## أين تُحفظ البيانات

| المسار | المحتوى |
|---|---|
| `users/{uid}/alerts/settings` | ما يُنبَّه عنه، الحدود، البريد، ساعة الإرسال والمنطقة الزمنية |
| `users/{uid}/alerts/push/{id}` | اشتراكات إشعارات الأجهزة |
| `users/{uid}/alerts/dismissed`, `sent`, `status` | المخفية، ما أُرسل، آخر إرسال وأخطاؤه |
| `alertsIndex/{uid}` | الحسابات المفعّل لها الإرسال (يكتبها الخادم فقط) |
| `alertsVault/_vapid` | مفاتيح إشعارات المتصفح (تُولَّد تلقائياً، الخادم فقط) |

لا تكتب الخدمة في أي عقدة يكتبها تطبيق الهاتف.

## النشر

يتطلب خطة Blaze. البريد يحتاج حساب SMTP (مثلاً Gmail بكلمة مرور تطبيق):

```bash
cd alerts && npm install
firebase functions:secrets:set ALERTS_SMTP_URL   # smtps://you%40gmail.com:app-password@smtp.gmail.com:465
firebase deploy --only functions:alerts
```

عند أول نشر يسأل Firebase عن `ALERTS_MAIL_FROM` (اسم وبريد المرسل، مثل `منصتي <you@gmail.com>`) و `ALERTS_APP_URL` (افتراضياً `https://inexusdev.com/monsati`).

ثم من الويب: التنبيهات ← الإعدادات ← فعّل البريد أو الإشعارات على الجهاز ← إرسال تجربة الآن.
