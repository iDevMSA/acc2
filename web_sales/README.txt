  المنصة المحاسبية — نسخة الويب (نظام المبيعات)
═══════════════════════════════════════════════════════════

الملفات:
  index.html  ← صفحة الويب الرئيسية
  style.css   ← التصميم
  app.js      ← منطق التطبيق والمزامنة مع Firebase

كيفية الاستخدام:
─────────────────
الطريقة 1: فتح مباشر (بدون CORS)
  افتح index.html في المتصفح مباشرةً.
  ملاحظة: بعض المتصفحات تمنع ES modules عند فتح الملفات مباشرةً.
  الحل: استخدم Firefox أو شغّل خادم محلي.

الطريقة 2: خادم محلي (موصى به)
  إذا كان Python مثبتاً:
    python -m http.server 8080
  ثم افتح: http://localhost:8080

الطريقة 3: رفع على Hosting
  ارفع المجلد web_sales/ على:
  - Firebase Hosting  (موصى به — نفس المشروع)
  - Netlify / Vercel
  - أي استضافة ويب عادية

تسجيل الدخول:
──────────────
  نفس بيانات تسجيل الدخول في التطبيق (email + password)
  المزامنة تلقائية وفورية مع Firebase Realtime Database

الميزات:
────────
  ✓ مزامنة فورية مع التطبيق في كلا الاتجاهين
  ✓ لوحة تحكم مع KPIs اليوم
  ✓ إدارة الفروع والمخازن والمنتجات
  ✓ عرض الموظفين
  ✓ عرض الفواتير مع التفاصيل الكاملة
  ✓ تقارير وإحصائيات (رسوم بيانية)
  ✓ برنامج الولاء
  ✓ إعدادات الشركة والعملة (60+ عملة)
  ✓ تصميم متجاوب (موبايل + ديسكتوب)
  ✓ واجهة عربية RTL كاملة

Firebase Hosting (اختياري):
────────────────────────────
  1. ثبّت Firebase CLI: npm install -g firebase-tools
  2. firebase login
  3. firebase init hosting  (اختر web_sales/ كمجلد عام)
  4. firebase deploy
