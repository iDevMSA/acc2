  manifest.json           ← PWA manifest + shortcuts
  firebase.json           ← إعدادات Firebase Hosting

🚀 بدء التشغيل السريع:
─────────────────────
طريقة 1: خادم محلي (الأفضل للتطوير):
  # إذا كان Python 3 مثبتاً:
  python -m http.server 8080

  # أو باستخدام Node.js:
  npm install -g http-server
  http-server -p 8080 -c-1

  ثم افتح: http://localhost:8080

طريقة 2: Firebase Hosting (للإنتاج):
  # ثبّت Firebase CLI
  npm install -g firebase-tools

  # تسجيل الدخول
  firebase login

  # نشر
  firebase deploy --only hosting

طريقة 3: أي خادم ويب (Apache, Nginx, etc):
  - انسخ محتويات web_sales/ إلى مجلد الاستضافة
  - تأكد من إعادة توجيه جميع الطلبات إلى index.html (SPA)
